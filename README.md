# MovieFlix

MovieFlix is a movie search app built with HTML, CSS, and vanilla JavaScript. It queries the OMDb API as you type and displays matching titles, release years, and posters in a responsive gallery.

**[Open MovieFlix](https://profitcoder.github.io/MovieFlix/)**

## Features

- **Live search** — Results update as you type a title into the search field.
- **Responsive gallery** — Poster cards adapt to desktop and mobile screens.
- **Fallback artwork** — Titles without a poster display a custom “Poster Not Available” image.
- **Lightweight setup** — The project uses native browser APIs and requires no package installation or build step.

## Built with

| Technology | Purpose |
| --- | --- |
| HTML5 | Page structure and search interface |
| CSS3 | Dark theme, responsive grid, and card styling |
| Vanilla JavaScript | Search events, API requests, and dynamic rendering |
| [OMDb API](https://www.omdbapi.com/) | Movie data and poster URLs |
| GitHub Pages | Hosting for the live demo |
